<h2><a href="https://www.geeksforgeeks.org/problems/three-consecutive-duplicates2434/1">Repeated Removal of 3 Consecutive Duplicates</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given a string <strong>s</strong>, repeatedly remove any group of exactly three consecutive identical characters. After each removal, concatenate the remaining parts of the string and continue removing such groups until no more removals are possible. Return the final string after all possible removals. If the resulting string is empty, return <strong>"-1"</strong>.</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> s = "aabbbaccddddc</span><span style="font-size: 18px;"><span style="font-size: 14pt;">"
<strong>Output:</strong> ccdc
<strong>Explanation:</strong></span></span><span style="font-size: 14pt;"> First remove "aaa" to obtain "bbbaccdddddc". Next remove "bbb" to obtain "accdddddc". Finally, remove "ddd" to obtain "ccddc". No more groups of three consecutive identical characters remain, so the reduced string is "ccddc".</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> s = "aaabbbccc</span><span style="font-size: 18px;"><span style="font-size: 14pt;">"
<strong>Output:</strong> -1
<strong>Explanation:</strong></span></span><span style="font-size: 14pt;"> Remove "aaa" to obtain "bbbccc". Next remove "bbb" to obtain "ccc". Finally, remove "ccc" to obtain an empty string. Since no characters remain, return "-1".<br></span></pre>
<p><span style="font-size: 18px;"><strong style="font-size: 18px;">Constraints:<br></strong></span><span style="font-size: 18px;"><span style="font-size: 18px;">1 ≤ |s| ≤ 10<sup>5</sup></span></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Strings</code>&nbsp;
